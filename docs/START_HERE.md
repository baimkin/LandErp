# LandErp — маршрут чтения и выполнения

## 1. Зачем этот файл

В репозитории находится полная дорожная карта LandErp. Она нужна, чтобы решения
не терялись, но агенту нельзя одновременно читать и реализовывать весь комплект.

Единственный рабочий указатель:

`docs/03-active/ACTIVE_TASK.md`

Если в нём нет активного Gate либо запрос пользователя не подтверждает его
выполнение, код изменять нельзя.

## 2. Что читать для текущего первого этапа

Только:

1. `AGENTS.md`;
2. `docs/03-active/ACTIVE_TASK.md`;
3. `docs/02-decisions/ADR-001_Платформа_и_версии.md`;
4. `docs/02-decisions/ADR-006_Политика_зависимостей_и_UI-база.md`;
5. `docs/03-active/SPIKE-001_Проверка_жизнеспособности_парсинга_Avito.md` —
   только разделы, указанные Gate;
6. `docs/03-active/TP-SPIKE-001_План_реализации_прототипа_Avito.md` — обзор
   границ и последовательности;
7. `docs/03-active/GATE-SPIKE-001-01_Каркас_и_контракты.md` — единственное
   исполняемое задание.

## 3. Что сейчас не читать

Без конкретной необходимости не читать:

- `docs/04-foundation/`;
- `docs/05-collection/` кроме точного файла, разрешённого Gate;
- `docs/06-manager/`–`docs/10-future/`;
- `docs/11-operations/`;
- `docs/12-task-plans-foundation/`;
- `docs/14-ui-kit/`.

Эти документы не удалены, но активируются позже.

## 4. Иерархия документов

| Уровень | Назначение | Разрешает писать код |
|---|---|---|
| MASTER | Общая цель и архитектурное направление | Нет |
| ADR | Обязательное архитектурное решение | Нет |
| FP | Проектирование крупной функции | Нет |
| SPIKE | Исследовательская программа и критерии решения | Нет |
| TP | План реализации серии Gate | Нет сам по себе |
| GATE | Ограниченный проверяемый этап | Да, после явного утверждения пользователем |
| REPORT | Факты выполнения и результат проверок | Нет |

## 5. Порядок завершения Gate

1. Выполнить только scope Gate.
2. Запустить указанные проверки.
3. Создать отчёт по шаблону.
4. Остановиться.
5. Дождаться review и отдельного решения о следующем Gate.

Агент не меняет `ACTIVE_TASK.md` на следующий этап самостоятельно.
