## План

### Утверждённое расширение 13 сентября 2026 года

Владелец после обсуждения подтвердил фиксацию плана и начало реализации.
Это расширение текущего Gate 02; Gate 03–08 не активируются.

1. Поле количества страниц: 1 по умолчанию, предел 10. Открытие ссылки
   ничего не собирает; только «Спарсить» запускает последовательный сбор.
2. Колесо мыши небольшими шагами с ожиданием подгрузки DOM; накопление
   карточек на каждом шаге, без потерь при виртуализации. Переход только
   по доступной ссылке следующей страницы Avito, без конструирования URL.
   Не более 120 шагов на страницу; достижение предела означает неполный сбор.
3. Дедупликация по реальному ID, прогресс, «Остановить», сохранение результатов
   по мере сбора. CAPTCHA/вход/ограничение доступа — пауза с заметным сообщением.
   «Продолжить» доступно только для ручного возобновления; автоматических
   retries, обхода защиты и маскировки действий нет.
4. Дополнительно из выдачи: цена за сотку, краткое описание, имя и информация
   продавца, отметки, URL одного превью. Полные detail-страницы не открываются.
5. SQLite: объявления, исходные наблюдения и журнал запусков. Отсутствующие
   поля нового наблюдения не очищают ранее найденные значения. В окне — поиск,
   сортировка, детали с состояниями полей и история наблюдений/запусков.
6. Проверки: locked restore, Release build, offline/synthetic tests,
   format, NuGet audit/лицензии, CLI, визуальная проверка окна, diff/секреты.
   Реальные многостраничные запросы не запускаются автоматически; владелец
   проверяет их вручную. Предыдущий live-результат не доказывает новую пагинацию.

Зависимость хранения: Microsoft.Data.Sqlite 10.0.0, MIT, поддержка Microsoft;
SQLitePCLRaw.bundle_e_sqlite3 2.1.13 (Apache-2.0) с нативной SQLite
изолирован в ListingStore, без EF Core. Явное закрепление 2.1.13 необходимо:
выпуск 2.1.11, подтянутый по умолчанию, имеет GHSA-2m69-gcr7-jv3q.
BCL не содержит SQLite provider. Выбор SQLite согласован в обсуждении;
владелец обновлений — технический владелец Spike. CPM и lock-файлы обязательны,
лицензии и известные уязвимости всего дерева проверяются после restore.
SQLite — локальный инструмент отладки, не схема будущего production-хранилища.
Локальная база в игнорируемой `local-data/`; cookies/headers/HTML не сохраняются.

## Поведение

При запуске окно ничего не открывает и не парсит. «Открыть страницу» запускает
браузер и загружает только введённую ссылку. «Спарсить» читает текущую страницу
только по нажатию. Авторизация и CAPTCHA выполняются вручную; повторное нажатие
после ручных действий разрешено. Автоматических retries, пагинации и обхода защиты нет.
До трёх навигаций за запуск; результаты текущего запуска показываются в окне.
Отсутствующие поля и ошибки видны; неизвестное состояние не означает пустой успех.
JSON сохраняется по отдельной кнопке, без HTML, cookies, headers и путей профиля.

## Зависимости и исключение из прежнего порядка

WPF входит в Windows Desktop .NET, сторонний UI framework не нужен.
Playwright одобрен владельцем в согласованном сценарии; официальный пакет
изолирован браузерным адаптером, версия закреплена в CPM. Лицензия MIT,
поддержка Microsoft; лицензии транзитивных пакетов и уязвимости проверить
при restore. Обновления принадлежат техническому владельцу Spike.
Chrome/Edge используются установленными; браузеры не скачиваются автоматически.

Прямой запрос владельца заменяет прежний scope Gate 02 и разрешает минимальный
UI, профиль, селекторы и live-проверку раньше fixture harness. Документ
`GATE-SPIKE-001-02_Fixture_harness.md` отложен и не является активным заданием.
Тесты минимальные и проверяют реальные инварианты; глубокий harness не строить.
