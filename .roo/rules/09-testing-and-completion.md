# LandErp — тестирование и завершение

- Дефект по возможности начинается с воспроизводящего теста.
- Бизнес-правила покрывать unit tests; EF/очередь/авторизацию — integration tests;
  границы — architecture tests; source adapter — fixture contract tests.
- Критический пользовательский путь покрывать E2E после стабилизации слоя.
- Интеграционные тесты используют реальный PostgreSQL, а не замену in-memory.
- Проверять cancellation, concurrency, idempotency, late delivery и отсутствие права.
- Не отключать и не ослаблять тест для прохождения CI.
- Перед завершением выполнить применимые format, build и test команды.
- Сообщать точные команды и результаты, включая непройденные проверки.
- Definition of Done из TP обязателен полностью; незавершённое не прятать в TODO.
