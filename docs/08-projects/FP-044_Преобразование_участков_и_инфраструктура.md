# FP-044 — Преобразование участков и инфраструктура

**Версия:** 0.1  
**Статус:** Черновик  
**Модули:** ProjectsFinance, PropertyCatalog  
**Зависимости:** FP-034, FP-041–FP-043; FP-060 позднее

## 1. Результат

Система хранит происхождение земли: какие исходные участки куплены, как они
объединялись/разделялись, какая площадь ушла на дорогу и какие конечные лоты
созданы. Юридический объект и проектный эскиз не смешиваются.

## 2. Модель происхождения

`LandAsset` — зарегистрированный/подтверждённый участок. `TransformationPlan` —
проектная версия. `TransformationEvent` — подтверждённый раздел/объединение/
изменение. `ProjectLot` — коммерческий результат, который до регистрации может
быть только planned. Связи образуют проверяемый граф происхождения.

## 3. Инфраструктура

Дороги, проезды, общие зоны и коммуникационные коридоры имеют геометрию/площадь,
правовой статус, владельца, стоимость и связь с лотами. Две сотки дороги в кейсе
Химки должны явно уменьшить продаваемый остаток с 30 до 28 соток.

## 4. Целостность

Сумма распределённой площади сверяется с исходной с допуском и объяснённым
остатком. Один зарегистрированный актив не исчезает при создании planned lots.
Кадастровый номер присваивается только подтверждённым документом.

## 5. UI

Дерево/граф «до → после», список лотов, площади, статус регистрации и общая
инфраструктура. До PostGIS геометрии допускаются как файлы/эскизы; числа всё
равно проходят баланс площади.

## 6. Тесты и DoD

- происхождение каждого лота прослеживается;
- planned и registered визуально различны;
- баланс площади учитывает дорогу/общие зоны;
- новая версия плана не меняет факт;
- продажа возможна только для подходящего статуса;
- документы и переходы прав защищены и аудируются.

## 7. Открытые вопросы

- модель владения дорогой/общими зонами;
- допустимый балансный допуск;
- интеграция с кадастровыми данными;
- момент создания коммерческого ProjectLot.
