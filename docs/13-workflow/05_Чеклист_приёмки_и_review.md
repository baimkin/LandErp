# Чеклист приёмки реализации

## Результат

- [ ] Реализован именно сценарий TP.
- [ ] Нет скрытого расширения scope.
- [ ] UI/API дают заявленный результат.
- [ ] Известные ограничения перечислены.

## Архитектура и данные

- [ ] Соблюдены направления project references.
- [ ] Данные изменяет модуль-владелец.
- [ ] EF entities не покидают Infrastructure/API boundary.
- [ ] Нет универсального `Common`, repository или service без причины.
- [ ] Миграция проверена на чистой и предыдущей схеме.
- [ ] Время, деньги, площадь и идентификаторы используют принятые типы.

## Безопасность

- [ ] Право проверяется сервером.
- [ ] Есть отрицательный тест доступа.
- [ ] Секреты, cookies и персональные данные не попали в diff/логи.
- [ ] Внешний HTML и имена файлов считаются недоверенными.
- [ ] Критичное действие аудируется.

## Качество

- [ ] `dotnet format --verify-no-changes` прошёл.
- [ ] `dotnet build` прошёл с warnings-as-errors.
- [ ] Релевантные unit/integration/architecture/contract/E2E тесты прошли.
- [ ] Нет отключённых тестов и необъяснённых suppressions.
- [ ] Diff прочитан человеком.
- [ ] Документация и статус TP обновлены.
