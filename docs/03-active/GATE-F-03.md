# F-03 — сортировка ₽/сот. и архив объявлений

Прямой запрос владельца, 2026-09-26. Продолжение поверх F-01/F-02 в ветке
`codex/f-01-search-groups-filters`, база `243a61f`. Незакоммиченные изменения
и отчёты сохранены, визуальная приёмка предыдущих задач не подтверждена.

## Scope и переходы

- Новая сортировка PricePerSotka добавляется в конец enum для совместимости;
  серверный порядок до Skip/Take, неизвестные в конце в обоих направлениях,
  равные значения упорядочены по ID. Общая цена остаётся доступной.
- Сортировка хранится существующим JSON сохранённого фильтра, без schema migration.
- Архив использует ту же страницу/таблицу/detail. Только Dismissed, Duplicate,
  RemovedAtSource, Fake, Sold. PossibleDuplicate не является архивным состоянием.
- При входе: сохранить текст, группу, сортировку; сбросить сохранённый фильтр,
  рабочий срез, цены и прочие условия. Сервер тоже нормализует архивный запрос,
  не полагаясь на отсутствие старых условий в UI. Нет OR рабочих фильтров.
- Возврат: режим SavedFilters, состояние Incoming, без прежнего выбранного
  фильтра/среза/архивного состояния; текст, группа и сортировка сохраняются.
- Архивные вкладки: Все / Не подходит / Дубли / Снято / Фейки / Продано.
  Поиск и группа остаются видимыми; рабочие плитки/пресеты в архиве не показываются.
