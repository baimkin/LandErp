## Решения и поведение

Сбор включается только кнопкой очереди. Диагностическая запись JSON необязательна:
карточки берутся из `/js/1/map/items`, контур из `/web/1/map/markers`, только в принадлежащей задаче вкладке.
Извлекаются реальные ID/URL, название, цена, описание, адрес, дата, фотографии,
площадь/назначение из текста и проверенная пара координат. Доступные поля продавца,
статистика, значки и цена за сотку дополняются из DOM, без раскрытия телефона.
Сырые ответы, cookies, auth headers, аккаунтные поля не записываются в базу/отчёт.

Сохраняется исходный GeoJSON Polygon с замкнутыми кольцами, включая отверстия.
Прямоугольник обзора из URL не подменяет контур. Для исходного drawId нужны контур
и сохранённый идентификатор в текущем URL. Пропажа/смена drawId, исчезновение или
смена контура блокируют источник с уведомлением. Восстановление исходной зоны
проверяется кнопкой «Продолжить Avito». При невозможности — остановить задачу и
сохранить новый поиск с новой областью. Автоматического восстановления нет.
Внешние точки и явно похожие/внешние объявления не добавляются в выбранную область;
неполные координаты не создают положение объекта.

Колесо работает над scroll-контейнером правого списка; размеры окна учитываются.
Используются существующие настройки шага/частоты колеса. Карта считается одной
логической страницей. MaxPages ограничивает принятые порции items, включая повторы;
счётчик уникальных объявлений не увеличивается от повторов.
Успех требует стабильного конца списка без загрузки/ошибок и совпадения уникальных ID
с totalCount. При отсутствии счётчика/несовпадении/лимите данные частичные, успешное
покрытие не записывается, следующая попытка начинает карту с начала.
Сеанс диагностики показал 59 строк / 50 уникальных ID: такой сбор считается неполным.

Объект уникален по Source+ExternalId. Идентичное наблюдение обновляет last seen и
связь с поиском, без новой истории. Изменение и возврат цены A→B→A сохраняются;
свежесть не блокирует запись уже полученного изменения. Отсутствующее поле не стирает
известное. Старое наблюдение не заменяет новое состояние. Свежесть управляет обходом:
пропущенный источник не позволяет узнать, изменились ли данные на сайте.

## Ограничения и испытание владельцем

Рабочая сборка:
`artifacts/local-001-map/bin/LandErp.ParserSpike.Desktop/release/LandErp.ParserSpike.Desktop.exe`.
Закрыть прежнее приложение, затем запустить новую сборку; база/поиски/профили сохранятся.
Обновление пользовательской базы выполняется только при запуске нового приложения
после эксклюзивного захвата базы, с резервной копией. Во время реализации пользовательская
база не мигрировалась, пользовательские окна/профили не закрывались.

Сохранить ссылку карты с нужной областью, отметить её, установить предел 10 порций,
для первого испытания включить «Начать заново», нажать «Обработать отмеченные».
Проверить движение правого списка, число уникальных объявлений/ориентир счётчика,
координаты/описание/фото в сохранённых объявлениях и контур в экспорте задачи.
Повторный принудительный запуск должен сохранить изменения, не дублируя одинаковую историю.
Для проверки сброса области использовать отдельный поиск; уведомление и пауза ожидаемы.

Точность координат не установлена: precision сохраняется как код источника, не в метрах.
Внутренние JSON-схемы сайта могут измениться; live-стабильность требует вашего испытания.
Парсер карты Cian, detail/телефоны, собственная карта, сетевые cursor и автоматическое
восстановление полигонов не реализованы. Сервер/worker/production/другие Gate не начаты.
Следующий шаг — ручное испытание владельцем; приёмка, закрытие SPIKE и Go не объявлены.
