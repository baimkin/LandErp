# FP-051 — Проектные права инвестора

**Версия:** 0.1  
**Статус:** Черновик  
**Модули:** IdentityAccess, InvestorPortal  
**Зависимости:** FP-002, FP-041, FP-050

## 1. Результат

Инвестор A не может получить проект, документ, финансовое событие или обращение
инвестора B ни через интерфейс, ни прямым API-запросом.

## 2. Модель доступа

`InvestorProjectGrant` связывает UserId, ProjectId, роль участия, разрешённые
разделы, период действия, основание, автора и статус. Рекомендуемые permissions:
ViewSummary, ViewPublishedFinance, ViewPublishedDocuments, ViewUpdates,
CreateInquiry. Grant не даёт доступ к внутренним комментариям и draft-данным.

## 3. Правила

- проверка выполняется сервером на каждом use case;
- project scope применяется к запросам списка и объекта;
- публикация данных и grant — два независимых условия;
- отзыв действует немедленно для новых запросов/сессий;
- Admin не использует интерфейс Investor как способ обойти аудит;
- отсутствие grant возвращает NotFound/Forbidden по единой политике без утечки.

## 4. Администрирование

Назначение показывает preview разрешённых разделов и требует основание. Массовое
назначение не входит в MVP. История grant неизменяема; исправление создаёт новую
версию/отзыв.

## 5. Тесты и DoD

- матрица A/B для каждого endpoint и файла;
- отозванный grant прекращает download;
- draft не виден даже с grant;
- list не выдаёт количество чужих проектов;
- прямой ID и подмена параметра не обходят scope;
- аудит grant/revoke и скачивания;
- отрицательные тесты обязательны для каждой новой инвесторской фичи.

## 6. Открытые вопросы

- типы участия и их права;
- кто назначает/отзывает grant;
- срок действия после закрытия проекта;
- политика доступа представителей инвестора.
