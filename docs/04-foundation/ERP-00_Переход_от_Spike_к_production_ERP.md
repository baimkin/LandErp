# ERP-00 — переход от Spike к production ERP

**Версия:** 1.0\
**Дата выполнения:** 2026-09-14\
**Статус:** Выполнен документационно по прямому запросу владельца.\
**Код:** не изменяется; ERP-01 не реализован, production migrations отсутствуют.\
**Thinking:** High.

## Цель

Закрыть исследовательский режим SPIKE-001 и подготовить первый production Gate
без переписывания Collector и противоречий в документации.

## Фактический результат

[Итог SPIKE-001](../03-active/SPIKE-001_RESULT.md) фиксирует:
локальный Collector Avito/Cian реализован, 85 offline tests passed,
владелец сверил 43 карточки карты Avito. Более широкая формулировка исходного
чеклиста «работает на реальных Avito/Cian поисках» не принимается за измеренное
подтверждение обоих источников: полный live acceptance Cian, detail parser,
вторая машина и длительная эксплуатация по отчётам не подтверждены.

Исследовательская фаза закрыта. **Conditional Go относится к отдельному
техническому основанию ERP**, которое можно строить независимо от browser-сбора.
Общий Go и production-приёмка Collector не объявлены; открытые проблемы
localPriority, Avito на лимите и критерий полноты карты сохраняются.

[Отчёт ERP-00](../03-active/reports/ERP-00_REPORT.md) содержит
reuse/adapt/experimental, ревизию TP-001–TP-010, evidence и ограничения веток.
Ветка документации создана до checkpoint Collector; код остаётся в
`spike/001-avito-viability`, история не объединялась.

## Выполненные действия

1. Зафиксирован фактический итог и границы подтверждённых проверок Spike.
2. Collector разделён на reuse/adapt/experimental без изменения приложения.
3. Утверждённый ADR-007 принят обязательной границей Collector ↔ Server:
   API/contracts, никакого browser-кода Server и PostgreSQL-доступа Collector.
4. FP-004 и бизнес-карта приняты как обязательные вводные, без разрешения
   реализовать их полный объём.
5. Устаревший общий запрет Spike снят в AGENTS; ACTIVE_TASK указывает только ERP-01.
6. README/START_HERE/Required reading обновлены под новую фазу.
7. Старые TP пересмотрены и помечены как материалы; старый порядок не активен.
8. Подготовлен один [ERP-01](../03-active/GATE-ERP-01_Техническое_основание_и_БД.md):
   foundation/БД, без Identity, Workflow, Collector integration, UI и бизнес-модулей.

## Definition of Done

- Spike больше не формальный блокер ERP; непроверенное не объявлено проверенным.
- Collector сохраняется самостоятельным приложением.
- ACTIVE_TASK содержит ровно один следующий Gate, со статусом «подготовлен».
- START_HERE и Required reading соответствуют фазе.
- Gate ограничен ERP-01.
- Production-код и migration не создавались; финальный review conventions обязателен.

**После ERP-00 ERP-01 может быть отдельно утверждён владельцем.**
Завершение документационного перехода само по себе не разрешает его реализацию.
