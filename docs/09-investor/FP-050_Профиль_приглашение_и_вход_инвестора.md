# FP-050 — Профиль, приглашение и вход инвестора

**Версия:** 0.1  
**Статус:** Черновик  
**Модули:** IdentityAccess, InvestorPortal  
**Зависимости:** ADR-004, FP-002, FP-003

## 1. Результат

Инвестор получает закрытый доступ только по приглашению, создаёт профиль,
безопасно входит и видит лишь назначенные ему проекты. Самостоятельной публичной
регистрации и каталога инвестиций нет.

## 2. Поток

Администратор создаёт приглашение для конкретного email/идентификатора со сроком
и предполагаемым project scope. Получатель подтверждает канал, принимает
актуальные условия, создаёт credential/MFA по политике и видит пустой либо
назначенный портфель. Повторное/истёкшее приглашение не работает.

## 3. Профиль

Минимум: имя, контакт, предпочтительный канал, язык/часовой пояс, статус и
принятые версии документов. Паспортные/банковские данные не собираются без
утверждённой юридической необходимости и отдельной защиты.

## 4. Безопасность

Rate limit, secure cookie, CSRF, MFA по принятой политике, отзыв сессий,
уведомление о критичных изменениях. Investor не может назначить себе проект или
роль через API. Восстановление доступа завершает старые сессии по политике.

## 5. UI

Брендированный, но простой поток: приглашение, создание доступа, вход,
восстановление и профиль. Ошибка не раскрывает существование чужого email.
Условия и согласия доступны после входа с версией/датой.

## 6. Тесты и DoD

- invite одноразовый и истекает;
- неподтверждённый пользователь не входит;
- нет self-registration;
- смена email/credential аудируется;
- Investor не получает внутренние роли;
- recovery и revoke работают;
- персональные данные минимальны и защищены.

## 7. Открытые вопросы

- канал приглашений и MFA;
- обязательные согласия/документы;
- юридический набор профиля;
- политика блокировки и поддержки.
