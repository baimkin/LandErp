## Production: обнаруженный пробел и разрешённое исправление

Для существующей production-организации не подключено заполнение канбана:

- миграция `20260928095409_KanbanPipelines` создаёт таблицы/индексы, но не начальные воронки/участие объектов;
- `KanbanProvisioning.InitializeAsync` вызывается из LocalSetup, но не из команды `ProductionSetup database`;
- production database выполняет migrations, grants и синхронизацию Access; существующие организации при этом не получают начальную воронку;
- новый объект использует `JoinNewCaseAsync` и `SingleAsync` для действующей основной воронки: при её отсутствии создание объекта может завершиться ошибкой;
- новый первый Owner получает воронку через общий bootstrap, поэтому проблема относится к обновлению существующих организаций, а не только к созданию чистой БД.

После аудита владелец отдельно поручил исправить тесты и подключить заполнение. `ProductionDatabaseInitializer.InitializeAsync` теперь вызывает существующий `KanbanProvisioning.InitializeAsync` после миграций, до выдачи runtime-прав. Условие импорта проверяет отсутствие участия объекта в любой воронке, чтобы не добавлять уже распределённый объект обратно в основную. Server/Worker startup по-прежнему не изменяет базу. Production не запускался.

Новый тест `ProductionUpgradeImportsOnlyUnpositionedActiveCasesAndPreservesRepeatedRuns` воспроизводит БД до канбана, обновляет её через настоящий production initializer, проверяет импорт активного объекта, исключение acquired/rejected, создание воронок для организаций, сохранение бизнес-состояния/версии/задач/назначений/истории, сохранение перемещённой карточки и участия в другой воронке при двух повторах. Также проверяется создание нового объекта после обновления.

Сам перенос Git не обновляет production БД, права runtime, конфигурацию и release. После закрытия пробела нужен backup по runbook, проверка SQL миграций, явное обновление схемы/прав/данных и только затем переключение версии. Production-соединения и фактическое состояние production в этой задаче не проверялись.
