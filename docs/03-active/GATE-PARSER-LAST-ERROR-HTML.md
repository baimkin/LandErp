# PARSER-LAST-ERROR-HTML

Утверждён владельцем 22.10.2026. Ветка `codex/parser-reliability`.

- Один локальный `diagnostics/last-error.html` — очищенный снимок DOM на момент
  ошибки сбора в Local/Server; рядом `last-error.json` с временем, заданием,
  источником, безопасным адресом, причиной и статусом получения HTML.
- Новая ошибка заменяет прежнюю; успех сохраняет последний сбой. Если страницу
  получить нельзя, старый HTML удаляется, новая причина остаётся.
- Скрипты/встроенные состояния, обработчики, значения форм и секретные параметры
  исключаются. Cookies/storage/auth headers не читаются. Снимок не исполняет JS.
- Получение ограничено по времени/размеру; сбой диагностики не меняет результат
  сбора и доставку observations. Серверные ошибки доставки снимок не создают.
- Использовать существующую кнопку папки диагностики, показать постоянный путь
  и имена файлов. Добавить явную инструкцию доступа для агента в README.
- Файлы: Models.cs, DomSourcePage.cs, QueueRunner.cs, DiagnosticJournal.cs,
  новый helper LastErrorSnapshot.cs, WorkspaceWindow.xaml(.cs), адресные tests,
  README, ACTIVE_TASK, Gate и отчёт.
- Release build и небраузерные адресные тесты: замена, недоступная/зависшая
  страница, конкурирующие сбои, безопасность, семантическая ошибка и исключение,
  независимость от результата сбора. Браузер и live marketplace не запускаются.
- Рабочие данные/настройки и предыдущие изменения сохранить. Установку сборки,
  production, commit/push/merge не выполнять в рамках этого поручения.
