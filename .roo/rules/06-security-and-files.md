# LandErp — безопасность и файлы

- Авторизация проверяется сервером в каждом use case; скрытая кнопка не является защитой.
- Сотрудники/инвесторы используют ASP.NET Core Identity; Agent имеет отдельный credential.
- Инвесторский доступ всегда ограничен ProjectId и опубликованными версиями.
- Секреты, cookies, токены и connection strings запрещены в коде, diff и логах.
- Внешний HTML, URL, имена файлов и MIME считаются недоверенными.
- Файлы доступны через `IFileStorage`; метаданные, hash и права хранятся в PostgreSQL.
- Яндекс Диск допустим через официальный REST API и серверный adapter; не выдавать
  постоянные публичные ссылки.
- Критические изменения прав, бюджетов, публикаций и Agent состояния аудируются.
- Для нового endpoint добавлять отрицательный тест отсутствия права/чужого scope.
