неизменившийся комплект при каждой правке.

## Ограничения чтения и исполнения

Не обходить весь docs и не читать будущие планы «для полноты».
Required reading активного Gate — адресное исключение для foundation/decisions/master.
Остальные FP, TP-001–TP-010, планы сбора, UI-kit и бизнес-волны не активируются.
[Ревизия старых TP](03-active/reports/ERP-00_REPORT.md) сохранена в отчёте ERP-00.

ADR-007 обязателен: самостоятельный Collector, API/contracts между runtime,
никаких browser/WPF/SQLite зависимостей Server и доступа Collector к PostgreSQL.
ERP-01 не включает Identity, Workflow, UI, бизнес-модули или Collector integration.

Документационная ветка пока не содержит checkpoint кода Collector:
см. README и итог Spike. Не принимать старую плановую базу за фактическое
состояние реализации и не объединять ветки без отдельного разрешения.

## Что разрешает код

| Документ | Роль | Разрешает реализацию |
|---|---|---|
| MASTER / бизнес-карта | Направление и порядок | Нет |
| ADR | Обязательная архитектурная граница | Нет |
| FP | Проектирование и вводные | Нет |
| TP | План серии действий | Только если сам явно утверждён как активная единица |
| Gate | Ограниченный проверяемый этап | После прямого утверждения владельцем |
| Report | Факты и evidence | Нет |

## Завершение Gate

Выполнить только scope → фактически запустить обязательные проверки →
создать отчёт → остановиться. Следующий Gate требует отдельного решения.
ACTIVE_TASK меняется на следующий этап только по запросу владельца;
переход ERP-00 разрешён запросом 2026-09-14 и подготавливает ERP-01,
но не разрешает его реализацию. Исторический запрос CODEX_FIRST_TASK не активен.
