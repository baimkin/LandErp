## Состав и решения

Сохраняются четыре ранее реализованные группы:

- Incoming fast open/transfer и пакет A: bounded reads, совместные запросные CTE,
  batch metadata, отдельное основное чтение rows+exact Total и информационные числа,
  guards поздних ответов и сохранение подтверждённых результатов действий.
- Независимые повторы поисков: состояние по SearchId, sending/queued/running,
  ошибка/неопределённый ответ и refresh без ложного подтверждения. Архивная защита
  main сохранена в новом UI helper; backend не меняется.
- Черновики осмотра: объединение ответов вкладок, выбор полей при пересечении,
  сохранение позднего ввода и короткая сериализация answer-save/completion.
- Отдельный Parser: браузерный lifetime/cancellation, безопасная диагностика,
  область и идентичность поиска, список/карта/пагинация, готовность новой карты,
  уведомления о необходимости ручного действия. Server не получает browser/WPF.

Их контракты, реализация, тесты, fixtures, спецификации, Gate и отчёты переносятся
вместе. Новых migrations, таблиц, grants, пакетов и изменения версий зависимостей нет.
Пакет B не реализован. Документы NOV19 из main сохранены.

До синхронизации status содержал 254 пути: 118 эквивалентны main после CRLF/BOM,
53 отличаются, 83 отсутствуют в main. Из реальной разницы исключены два изображения
пользователя; 134 пути составляют проверенные доработки и документацию. Изменения
только BOM двух скриптов не публикуются как функциональная правка.

Дополнительные изменения текущего Gate: .gitignore для локальных вложений, краткий
ACTIVE_TASK с одним scope, архив полной локальной истории с дополнительными
историческими абзацами main, этот Gate/отчёт. Билды, TRX, измерения, сертификаты,
local-data, настройки, профили браузера и пользовательские вложения не коммитятся.
Вложения сохраняются на диске. Исторические запреты commit/push в старых отчётах
описывают прежние запросы; текущий запрос прямо разрешает эту публикацию.

## Ограничения и следующий шаг

Последние измерения A: page 1.482–1.976 s на 25k listings/500k observations/50 filters;
7.689–9.733 s на 100k/2m/100. На большом объёме остаются latency/spill, универсальное
SLA 3 s не подтверждено. Известное ограничение bulk при конкурентной смене
group/time/view не исправлялось. Эти факты не активируют B.

Production и его БД не изменяются, развёртывание и установленный Parser не
обновляются. Новая server сборка отдельно не распространяет Desktop. Проверки не
доказывают доступность живых Avito/Cian, Яндекс Диск или поведение Safari/iPhone.

После подтверждения одинакового SHA основная рабочая папка остаётся на main.
Перед новой задачей проверить scope и свежесть origin/main; новые Gate/реализацию
начинать только по запросу владельца. Факт публикации отделён от этого файла,
чтобы не включать в commit собственный будущий SHA.
