# M-01 — участие объявлений в расчёте средней и медианы

Разрешён владельцем 2026-09-26. База `18a6a1f26089317d91d13823183e720d95530199`
(checkpoint F-01–F-03), ветка `codex/m-01-median-participation`.

## Scope

Одна общая для организации отметка Listing «Учитывать в расчёте»; существующие
записи false. Отдельные и массовые команды с Incoming.Process, серверной
изоляцией и проверкой версии; массовое действие использует тот же отбор, что
таблица, включая страницы и архив. Предварительно показывается количество.
История и audit используют существующие механизмы.

Необязательная настройка сохранённого фильтра автоматически включает только
впервые созданные пригодные объявления. Семантика условий F-01/F-02 сохраняется;
CompatibilityIssue не выполняется. Никакого backfill, повторного включения при
наблюдении, смене цены или новой группе. Применение/изменение/удаление фильтров
не меняет отметок. Пригодность: положительные цена и площадь, RUB; Duplicate,
Fake, RemovedAtSource запрещены и снимают отметку. Sold и Dismissed разрешены.
Возврат отметку не восстанавливает; существующее разделение группы получает
необязательную выключенную галочку. Решение владельца 2026-09-26: при потере
валидной цены/площади/валюты отметка сохраняется, строка временно непригодна.
Исправление данных возвращает пригодность без изменения отметки; ручное false
не восстанавливается. UI различает сохранённую отметку и пригодность, выключение
доступно при невалидных данных. Контракт для M-02: фактический состав расчёта =
IncludeInCalculation && CalculationIneligibility == null; сам расчёт здесь не менять.
