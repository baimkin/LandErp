## Scope и семантика

По умолчанию /incoming работает по OR применимых общих фильтров организации.
Внутри фильтра — AND всех его условий, включая группу и сохранённые состояние/срез.
Пустое OR даёт пустую выдачу; несовместимые фильтры явно перечисляются.
Выбор группы уточняет объединение. Выбор фильтра заменяет прежний выбранный
фильтр и его группу/условия; редактируемый черновик заменяет его сохранённые
условия локально, сохраняя ID и ожидаемую версию для явной записи F-01.

Переключение на весь поток снимает сохранённые фильтры и их скопированные условия,
но сохраняет группу, текст, состояние и активный срез. Архив автоматически не добавляется.
Срезы страницы заменяют друг друга, сохраняя базовый контекст. Для срезов Новые,
Цена, Неполные, Возврат используется Incoming; для дублей Incoming/Duplicate;
для Обработано сегодня — события решения вне зависимости от текущего состояния.
Сохранённые условия остаются AND: например сохранённый фильтр только Incoming
не начинает включать Fake при нажатии Обработано сегодня. Срезы ничего не пишут.

Счётчик альтернативного фильтра считает результат перехода на него: его полные
условия и группа + текущий текст и активный срез, без прежнего фильтра/его черновика.
Заголовок группы считает уникальное OR её фильтров в таком же контексте.
Первый пункт «Все сохранённые фильтры» возвращает объединение с текущей группой,
текстом и срезом, сбрасывая черновик на Incoming. Total/пагинация считают то же условие.

## Файлы и проверки

IncomingCatalogReadContracts, IncomingCatalogReadService, новый IncomingCatalogQuery,
IncomingCatalogV2; IncomingWorkingSelectionTests; ACTIVE_TASK, этот Gate и отчёт.
Общий механизм условий формирует SQL predicates для списка и условных агрегатов;
нет загрузки всех Listing и отдельных count-запросов для каждого фильтра.

Required reading: ACTIVE_TASK, F-01 Gate/отчёт, только затронутый код.
Схема БД не меняется. Проверки: одна Release-сборка test project/Server dependencies,
три F-02 теста, F-01 групповой отбор и два существующих теста New/ProcessedToday,
поскольку механизм чтения этих сценариев изменён. Только disposable PostgresSandbox.

Без браузера/Server/полного suite/Live/Parser tests, рабочей/production БД,
commit/push/merge/rebase/новой ветки. F-03 и соседние функции не входят.
