# Подключение к проекту LandErp

1. Распакуйте архив.
2. Скопируйте каталог `LandErp-UI-Kit` в репозиторий как `docs/ui-kit`.
3. Добавьте `docs/ui-kit/AGENT_UI_INSTRUCTIONS.md` в постоянный контекст или правила Zoo Code.
4. Для просмотра откройте `docs/ui-kit/ui-kit/index.html` в браузере.
5. При постановке UI-задачи указывайте агенту нужный экран и прикладывайте готовый префикс из инструкции.

Не подключайте файлы прототипа напрямую к рабочему приложению. При реализации переносите токены и компоненты осмысленно в структуру Blazor-проекта.
