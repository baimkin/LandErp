# Карта документов LandErp

| Каталог | Содержимое | Когда читать |
|---|---|---|
| `00-governance` | Реестр, журнал решений, шаблоны и маршрут согласования | При управлении планами и статусами |
| `01-master` | Генеральный архитектурно-технический план | При изменении границ продукта |
| `02-decisions` | Утверждённые ADR-001–ADR-006 | Только применимые к текущему Gate |
| `03-active` | Текущий Spike, TP, Gate, запрос и шаблоны отчётов | Всегда для активной задачи |
| `04-foundation` | Каркас, доступ и дизайн-система | После Spike и активации фундамента |
| `05-collection` | Поиски, очередь, Agent, Avito, каталог и качество | По конкретному FP/TP |
| `06-manager` | Рабочее место менеджера | После первого стабильного сбора |
| `07-due-diligence` | Проверки участка и экономика кандидата | После рабочего места менеджера |
| `08-projects` | Сделка, работы, раздел, продажи | После due diligence |
| `09-investor` | Лёгкий кабинет инвестора | После контролируемой модели проекта |
| `10-future` | PostGIS, второй источник, ИИ, сообщения, аналитика | Только после отдельной активации |
| `11-operations` | Установка, CI/CD, резервирование и инциденты | Вместе с соответствующим релизом |
| `12-task-plans-foundation` | Ранее подготовленные TP-001–TP-010 | Отложены до решения по Spike |
| `13-workflow` | Инструкции Zoo Code/DeepSeek и review | При настройке локальной разработки |
| `14-ui-kit` | Визуальный эталон ERP | Только при UI-задачах |
| `15-source-materials` | Правила работы с локальными HTML и диагностикой | Перед добавлением fixtures |

Полный реестр находится в `00-governance/00_Реестр_планов.md`, но агенту не
нужно читать его при каждом запуске.
