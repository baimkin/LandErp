# Отчёт — экран «Поиски и парсинг» v1.3

**Ветка:** `codex/collectors-v1-3-ui`  
**База:** `5b254b9` (`codex/integrate-server-property-v2`)  
**Дата:** 17 сентября 2026 года

## Результат

Техническая страница `/collectors` заменена законченным операторским экраном по
утверждённому макету. Реализованы:

- KPI активных поисков, Parser на связи, общей очереди и внимания;
- сводка проблем и переход к поискам, требующим внимания;
- группы с раскрытием, фильтры, агрегаты последних запусков и следующих сроков;
- создание, редактирование, ручной запуск, включение и приостановка поиска;
- управление группами;
- компактные карточки Parser со связью, текущей работой и прогрессом;
- одноразовый код подключения с понятным пользовательским сценарием;
- отдельный явный переключатель `CanManageSearches`, по умолчанию выключенный;
- перевыпуск токена и отключение Parser;
- scheduler health и постраничная история с деталями результата;
- адаптивное представление в изолированных стилях страницы.

Server остаётся единственным владельцем server groups/searches/jobs/queue/data.
Parser создаёт группы и поиски только через server API при выданном
`CanManageSearches`. Machine protocol, ParserSpike и страницы закупки не менялись.
