# Отложенные TP первого серверного контура

Документы `TP-001`–`TP-010` были подготовлены до выделения `SPIKE-001` как
первого обязательного этапа.

Они сохранены, но **не активны**. Codex и Zoo Code не должны начинать их по
номеру, пока:

1. не завершён `SPIKE-001`;
2. не принято `Go` или `Conditional Go`;
3. не учтены фактические ограничения источника;
4. владелец не актуализировал очередность и статус конкретного TP;
5. `docs/03-active/ACTIVE_TASK.md` не указывает на этот TP.

Первым активным документом является не `TP-001`, а
`docs/03-active/GATE-SPIKE-001-01_Каркас_и_контракты.md`.
