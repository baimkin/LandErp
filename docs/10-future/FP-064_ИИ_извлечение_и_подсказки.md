# FP-064 — ИИ-извлечение и подсказки

**Версия:** 0.1  
**Статус:** Черновик  
**Плановая реализация:** после создания контрольного набора и human review  
**Модули:** Collection, DueDiligence, ManagerWorkspace  
**Зависимости:** FP-014, FP-021, FP-030

## 1. Результат

ИИ помогает извлекать сложные признаки из описаний/документов и готовит
объяснимые подсказки, но не меняет юридический вывод, цену, лимит покупки или
статус объекта без подтверждения человека.

## 2. Допустимые первые сценарии

- предложить площадь/кадастровый номер/коммуникации из текста;
- классифицировать упоминания мусора, строений, подъезда и торга;
- сформировать вопросы для проверки;
- кратко суммировать изменения объявления со ссылками на исходные фрагменты;
- предложить PossibleMatch, не выполнять merge.

## 3. Контракт результата

Каждое утверждение содержит value, source fragment/page, model/version, prompt/
ruleset version, confidence и review status. Ответ без происхождения не попадает
в рабочие факты. Сырые prompt/response хранятся по privacy/retention политике.

## 4. Контроль качества

До запуска создаётся размеченный контрольный набор, метрики precision/recall по
важным полям и допустимые пороги. Высокорисковые ошибки оцениваются отдельно от
среднего качества. Новая модель проходит offline test и canary.

## 5. Безопасность

Внешнему провайдеру не отправляются лишние персональные/инвесторские данные.
Документ рассматривается как недоверенный ввод: prompt injection не меняет
системные права. Выход валидируется схемой и серверными правилами. Стоимость и
лимиты измеряются.

## 6. UI

Подсказка визуально отделена от подтверждённого факта; есть источник, принять,
исправить, отклонить и причина. Массовое автопринятие отсутствует в первом этапе.

## 7. Тесты и DoD

- контрольный набор и baseline;
- отсутствие факта без source span;
- модель не обходит permission;
- prompt injection fixtures;
- повтор/версия воспроизводимы настолько, насколько допускает модель;
- ошибки пользователя собираются для оценки, не для скрытого обучения;
- kill switch и ограничение стоимости.

## 8. Открытые вопросы

- конкретный первый сценарий и экономический эффект;
- допустимый провайдер/размещение данных;
- пороги качества;
- retention и юридические условия обработки.
