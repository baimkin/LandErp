# FP-042 — Сценарии и версии бюджета

**Версия:** 0.1  
**Статус:** Черновик  
**Модули:** ProjectsFinance  
**Зависимости:** FP-036, FP-041

## 1. Результат

Проект имеет несколько сравнимых сценариев и управляемые версии бюджета:
черновик, утверждённый baseline и факт. Изменение плана не стирает первоначальное
решение и не превращает прогноз в расход.

## 2. Модель

`ProjectScenario` задаёт лоты, работы, сроки и продажи. `BudgetVersion` содержит
строки доходов/расходов и состояния Draft, Submitted, Approved, Superseded,
Cancelled. `ActualTransaction` хранится отдельно и сопоставляется со строкой
бюджета.

## 3. Правила версий

Одновременно один действующий approved baseline. Новая версия создаётся копией с
происхождением, проходит сравнение и утверждение. Старый baseline становится
Superseded, но остаётся в plan–fact. Изменение курса/налога не меняет прошлый факт.

## 4. UI

Сравнение сценариев, diff версии, cash-flow по времени, потребность в капитале,
plan–fact и прогноз завершения. Цвет дополняется текстом. Скрытая точность не
создаётся: диапазоны/неизвестные показываются явно.

## 5. Права

Проектная команда готовит draft; утверждающая роль фиксирует baseline; финансист
сверяет факт. Investor видит только выбранную опубликованную версию и явно
обозначенные прогноз/факт.

## 6. Тесты и DoD

- один active baseline;
- суммы строк и cash-flow воспроизводимы;
- actual не меняется при новом budget;
- diff показывает добавление/удаление/изменение;
- конкурентное утверждение безопасно;
- план–факт связан с версиями;
- права и аудит утверждения проверены.

## 7. Открытые вопросы

- категории бюджета и налоговая модель;
- матрица утверждений;
- частота reforecast;
- поддержка нескольких валют и стоимости капитала.
