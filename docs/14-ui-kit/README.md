# LandErp UI Kit

Интерактивный эталон интерфейса LandErp для менеджеров, администраторов и инвесторов.

## Что включено

- дизайн-токены: цвет, типографика, интервалы, радиусы, тени и плотность;
- базовые элементы: кнопки, поля, переключатели, статусы, уведомления, вкладки и пагинация;
- таблицы и панели фильтрации для плотной операционной работы;
- карточка объекта, проверочные списки и история изменения цены;
- экран проекта с финансовыми показателями, планом/фактом и разделением участка;
- мониторинг локальных парсер-агентов;
- облегчённый кабинет инвестора;
- адаптивные состояния для компьютера, планшета и телефона.

## Техническая основа

UI-kit собран на HTML, CSS и JavaScript без внешних библиотек, шрифтов и CDN. Он предназначен как визуальный и поведенческий эталон для последующего переноса компонентов в Blazor. Все основные значения вынесены в `dist/tokens.css`.

## Структура

- `dist/index.html` — демонстрационные экраны и компоненты;
- `dist/tokens.css` — единые дизайн-токены;
- `dist/styles.css` — стили компонентов и адаптивность;
- `dist/app.js` — демонстрационные взаимодействия.
