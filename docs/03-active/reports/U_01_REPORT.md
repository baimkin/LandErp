## Результат

- Общая компактная лента: дата слева, бизнес-текст посередине, тип и короткий
  автор справа. Основной текст выводится один раз, даты и полное имя доступны
  в подсказках. Отображается дата действия при наличии, иначе дата регистрации,
  в МСК; исходный порядок сохраняется, для равных дат добавлен стабильный Id.
- Общий renderer используется в ходе работы, переговорах карточки, коротких
  лентах боковой панели и модальной истории переговоров. Полная техническая
  История использует прежний BusinessTimeline и исходные Title/Body.
- Сохраняются цены, условия, комментарий, следующий шаг, сроки и вложения.
  Подавляются только буквальные повторы полей. События задач не удаляются.
- В старой timeline нет NegotiationId: структура общения добавляется лишь при
  единственном полном совпадении организации/объекта, автора, дат и Body.
  При несовпадении или неоднозначности остаётся исходный текст события.
- Проверки, документы и осмотр в контроле объекта открываются целой кнопкой
  строки с focus/hover. Переходы из боковой панели в проверки и полную историю
  используют существующую карточку с параметром вкладки.
- Значки источников открывают реальные HTTP(S) URL в новой вкладке с
  noopener/noreferrer. Несколько источников одного типа дают выбор; без
  допустимого URL значок неактивен. URL не генерируются из идентификаторов.
