# INSPECTION-FILE-IMPROVEMENTS

29.10.2026. Владелец утвердил план в текущем чате. Ветка
`codex/inspection-file-improvements`; существующие изменения парсера сохраняются.

## Scope

- Несколько файлов осмотра/карточки, последовательная загрузка, результат каждого,
  стабильный UploadId для повтора без дублей. Ограниченная партия до 20 файлов.
- До 50 МБ на файл, согласованные проверки формы, application, storage и HTTP.
- Выбор галереи отдельно от съёмки камерой; оба сценария сохраняются.
- Мягкое удаление вложения, без физического удаления или новых прав.
  Существующее право редактировать досье этой карточки разрешает удаление
  и скачивание удалённого файла из существующей истории. Обычное чтение активных
  документов не меняется. Аудит и бизнес-событие фиксируются атомарно.
- Удалённое вложение исключается из текущих списков и наличия обязательного
  документа; metadata и содержимое сохраняются. Повтор удаления идемпотентен.

## Файлы

SiteInspectionPage, CaseWorkspace, CaseActivityFeed и связанный UI загрузки;
ProcurementContracts, ProcurementWorkspace, CaseTimelineAttachment,
ProcurementQueueV2ReadService (выборки); ProcurementEndpoints;
FileStorage, YandexDiskOptions/настройки HTTP при необходимости;
адресные Foundation tests; ACTIVE_TASK, Gate и итоговый отчёт.
Схема меняется только при доказанной необходимости; существующий Deleted
и metadata истории переиспользуются при возможности.

## Проверки

Release build (warnings as errors), адресные проверки на изолированных PostgreSQL,
границы размера, частичный сбой и повтор партии, отсутствие дублей,
мягкое удаление/сохранность файла, история/скачивание, повтор удаления,
чужая организация/карточка и read-only/inspector против edit permissions,
статус последнего обязательного документа; git diff --check.
Safari/iPhone и рабочая конфигурация сервера явно отмечаются как отдельная
ручная приёмка при отсутствии соответствующего устройства/среды.

Без новых пакетов, новых ролей, живой БД, обновления сервера, commit/push/merge,
изменений Collector или перехода к следующей задаче.

## Результат

Реализовано. Release build — 0 warnings/errors; 15/15 адресных небраузерных
проверок Passed; сквозной Edge headless — 1/1 Passed, включая загрузку настоящим
IBrowserFile видео 30 МиБ и сохранность физического файла после удаления.
