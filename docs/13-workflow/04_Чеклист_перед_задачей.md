# Чеклист перед началом TP

- [ ] TP имеет статус `Утверждён`.
- [ ] Указаны FP и ADR, которым он подчиняется.
- [ ] Результат описан одним проверяемым предложением.
- [ ] Перечислены входящие и не входящие изменения.
- [ ] Известны затрагиваемые проекты и модули.
- [ ] Нет скрытого выбора новой архитектуры.
- [ ] Новые пакеты перечислены и обоснованы либо отсутствуют.
- [ ] Определены права и отрицательные сценарии.
- [ ] Описаны миграция и rollback либо указано, что схемы БД нет.
- [ ] Определены unit/integration/architecture/E2E проверки.
- [ ] Для UI указаны loading, empty, error, forbidden и success.
- [ ] Для внешнего источника указаны fixture и ошибки качества.
- [ ] Рабочее дерево просмотрено, чужие изменения обозначены.
- [ ] Секреты и локальные профили исключены `.rooignore`.
- [ ] Владелец готов отдельно подтверждать запись и команды.
