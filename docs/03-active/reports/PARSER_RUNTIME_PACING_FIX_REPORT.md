# Parser runtime pacing fix

**Дата:** 2026-09-20  
**Ветка:** `codex/parser-runtime-url-stability`  
**База:** `3062c74`

## Причина

Диагностика живого запуска показала два независимых дефекта:

- карта Avito завершалась ошибкой после изменения динамических параметров URL;
- завершённая локальная работа ожидала heartbeat cadence до 45 секунд перед
  доставкой результата и получением следующего задания.

Кроме того, Runner продолжал прокрутку при `Loading=true`, из-за чего несколько
динамических загрузок могли пересекаться.

## Исправление

- Во время прокрутки карты authority являются тип страницы и подтверждённая
  геометрия зоны. Полное сравнение динамического URL оставлено только обычной
  постраничной выдаче.
- Пока источник сообщает `Loading=true`, новая прокрутка не выполняется. Runner
  опрашивает состояние с паузой 250 мс и сохраняет уже полученные наблюдения.
- Для карты между завершёнными шагами прокрутки действует минимальная пауза
  750 мс. Первая прокрутка начинается после завершения активной загрузки и
  появления первой порции данных либо после ограниченного ожидания.
- Длительная незавершённая загрузка завершается как `LOADING_INTERRUPTED`, а
  полезные данные сохраняются.
- Завершение локального Runner обходит 45-секундный heartbeat timer: результат
  отправляется на ближайшем секундном UI tick, после чего Parser запрашивает
  следующую работу.
