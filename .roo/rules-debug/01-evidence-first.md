# Debug mode — LandErp

- Сначала воспроизвести проблему и собрать факты без изменения кода.
- Отделить симптом, первопричину и сопутствующий технический долг.
- По возможности создать минимальный падающий тест до исправления.
- Не увеличивать retries, timeouts и suppressions без доказательства причины.
- Не удалять данные и не запускать destructive-команды.
- Исправление выполнять только после подтверждения владельца и в scope дефекта.
