# Расписания и управление Parser — доработка по аудиту

Дата: 17 сентября 2026. Ветка: codex/collectors-scheduling-ux.
База: объединённая codex/integrate-parser-ui-storage.

## Изменения

- В форме отдельные редактируемые времена (до 12 в сутки), добавление/удаление
  времени, интервалы в минутах/часах/днях с проверкой 5 минут — 7 дней.
- Серверный preview ближайшего запуска использует те же правила, что сохранение,
  и ничего не записывает. Все даты страницы — в часовом поясе организации.
- Явный необязательный первый сбор после сохранения (по умолчанию выключен).
  Поиск, первое задание и аудит записываются одним SaveChanges transaction.
  При выключенном флаге сохраняется прежний режим ожидания расписания.
- Название, URL, группа и лимит не переносят уже рассчитанный срок. Изменение
  расписания/включение после паузы рассчитывает новый. Null interval отклоняется.
- Группа создаётся прямо в форме и выбирается без потери введённого поиска.
- Карточки Parser размещены слева с постоянными промежутками, без растягивания
  колонок и пустого высокого блока ожидания.
- Группы явно отмечены; ссылки имеют отступ и направляющую. В колонке расписания
  группы отображается расписание, добавлен агрегат изменений.
- Доступны архивные группы; ссылки не исчезают без возможности просмотра.
  Для включения архивного поиска необходимо перенести его в действующую группу
  либо выбрать «Без группы». Переименование в архиве разрешено.
- Состояние обновляется каждые 15 секунд без замены вводимых полей и версий формы.
  Есть явное ручное обновление и сообщение об устаревших данных при сбое.
- Предупреждения раскрывают действительные причины, включая Worker и Parser,
  а не фильтруют случайным образом поиски. Ошибки сохранения видны внутри диалога.
- Достижение лимита не выделяется как ошибка; история явно ограничена последними
  100 заданиями. Время создания очереди не называется фактическим началом сбора.
- Start-Local.ps1 по умолчанию запускает собственный Worker вместе с Server,
  завершает его при выходе из сессии; ServerOnly сохраняет независимый запуск.
  Миграции launcher не применяет.
