# FP-055 — Обращения инвестора

**Версия:** 0.1  
**Статус:** Черновик  
**Модули:** InvestorPortal, ManagerWorkspace  
**Зависимости:** FP-025, FP-051, FP-052

## 1. Результат

Инвестор задаёт вопрос по назначенному проекту, видит ответственного, статус и
историю ответа. Внутренняя переписка команды не раскрывается.

## 2. Модель

`InvestorInquiry`: ProjectId, investor, category, subject, message, attachments,
status, assigned employee, SLA target и timestamps. Состояния New, InProgress,
WaitingInvestor, Answered, Closed. Внутренние notes отделены от внешних сообщений.

## 3. Поток

Инвестор создаёт обращение, система проверяет grant, назначает очередь/владельца,
сотрудник отвечает или запрашивает уточнение, инвестор получает уведомление в
кабинете. Закрытие сохраняет последнюю внешнюю формулировку.

## 4. Безопасность

Вложения проверяются и хранятся по ADR-005. Project scope действует на все
сообщения/файлы. Ответ сотрудника проходит preview; внутренний комментарий нельзя
случайно опубликовать одним переключателем.

## 5. Тесты и DoD

- обращение возможно только по своему проекту;
- внутренние notes отсутствуют во внешнем API;
- повтор отправки идемпотентен;
- вложение проходит quarantine;
- переназначение и ответ аудируются;
- просроченные обращения видны ответственному;
- закрытое можно переоткрыть по явной политике.

## 6. Открытые вопросы

- категории и целевые сроки ответов;
- команда/маршрутизация;
- внешние уведомления;
- retention переписки и вложений.
