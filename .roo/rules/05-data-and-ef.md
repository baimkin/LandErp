# LandErp — данные и EF Core

- PostgreSQL является источником транзакционной истины и очередью первого контура.
- Один основной DbContext на старте; конфигурация и таблицы имеют модуль-владелец.
- Использовать UUIDv7 для бизнес-ID, `timestamptz`/UTC для времени и `decimal` для денег.
- Деньги всегда имеют валюту; площадь — единицу и происхождение.
- EF entity не возвращается через API и не привязывается напрямую к Blazor UI.
- Миграции генерируются отдельно, проверяются на чистой и предыдущей схеме.
- Production-миграции не выполняются автоматически при запуске приложения.
- Опасное изменение схемы делать через expand–migrate–contract.
- Для истории и внешних наблюдений не перезаписывать факт без сохранения версии.
- Комментарии таблиц и значимых столбцов БД писать на русском.
