# Code mode — LandErp

- Реализовывать только один Gate или TP, указанный в `docs/03-active/ACTIVE_TASK.md`
  и явно утверждённый владельцем в текущем запросе.
- До изменения показать точные файлы, зависимости, команды и проверки.
- Каждая запись и команда требуют отдельного подтверждения владельца.
- Делать вертикальный результат небольшими логическими изменениями.
- Не менять публичный контракт, миграцию или пакет вне scope активного Gate/TP.
- После изменений выполнить одобренные format/build/test и показать diff.
