# Gate: экран «Поиски и парсинг» v1.3

## Статус и разрешение

- Статус: Completed; ожидает ручной визуальной приёмки владельцем.
- Разрешение владельца: 17 сентября 2026 года — полностью реализовать удобный экран управления парсерами по утверждённому макету.
- Ветка: `codex/collectors-v1-3-ui`.
- База: интеграционный HEAD `5b254b9` (`codex/integrate-server-property-v2`).

## Цель

Заменить техническую страницу `/collectors` законченным операторским экраном:
KPI, внимание, сгруппированный список поисков, управление расписаниями,
состояние и прогресс локальных Parser, очередь и история запусков, подключение
нового Parser и управление разрешением `CanManageSearches`.

Server остаётся владельцем групп, поисков, расписаний, заданий и очереди.
Локальный Parser может создавать группы и поиски только через server API и
только при включённом пользователем разрешении `CanManageSearches`.

## Scope

- `Collectors.razor` и изолированные стили страницы;
- необходимые дополнения Collection read model без изменения machine protocol;
- модальные сценарии подключения Parser, создания/редактирования поиска и групп;
- агрегаты групп, фильтрация, состояния, прогресс, история и подробности запуска;
- документация Gate и итоговый отчёт.

Не входят: страницы закупки, ParserSpike, браузерный слой Parser, новый источник,
изменение machine protocol, production apply, merge и push.

## Обязательные проверки

- Release build без warnings и errors;
- Collection foundation/unit tests;
- Collection PostgreSQL tests;
- `HasPendingModelChanges() == false`;
- migration-chain check и применение новой интеграционной migration к локальной
  `landerp_local`, если она ещё не применена.

Браузерные и визуальные тесты не выполняются по прямому решению владельца; ручную
проверку страницы выполняет владелец.

## Критерии завершения

- оператор видит состояние системы без технических Job/Lease деталей;
- поиск создаётся, редактируется, запускается и приостанавливается из одного экрана;
- Parser подключается одноразовым кодом и показывает связь, текущую работу и прогресс;
- разрешение локально создавать группы и поиски явно переключается и по умолчанию выключено;
- история и причины внимания читаемы, пустые/ошибочные состояния обработаны;
- изменения изолированы от закупки и подтверждены обязательными проверками.
