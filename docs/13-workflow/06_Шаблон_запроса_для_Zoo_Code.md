# Шаблон запуска задачи Zoo Code

```text
Работаем над LandErp по TP-NNN: <название>.

Сначала только анализ. Ничего не записывай и не выполняй команды.

Прочитай:
1. docs/.../TP-NNN...
2. связанный FP-...
3. ADR-...
4. фактические файлы рядом с изменением.

Затем покажи:
- понимание результата и границ;
- список файлов, которые потребуется создать/изменить;
- новые зависимости, если они действительно нужны;
- миграции и риски совместимости;
- проверки и точные команды;
- вопросы, только если ответ существенно меняет реализацию.

После моего подтверждения предлагай изменения небольшими логическими группами.
Любая запись файла и любая команда выполняются только после моего отдельного
одобрения. Не меняй ADR, scope и версии пакетов самостоятельно.
```

## Запрос на финальное review

```text
Не меняй файлы. Проведи review реализации TP-NNN по его Definition of Done.
Проверь diff, архитектурные границы, права, миграции, тесты, ошибки и отсутствие
лишних зависимостей. Сначала перечисли блокирующие проблемы, затем важные, затем
необязательные улучшения. Не предлагай рефакторинг вне scope без доказанной причины.
```
