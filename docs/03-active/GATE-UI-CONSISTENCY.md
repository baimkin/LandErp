# Gate — единый визуальный стандарт LandErp

Дата: 17 сентября 2026 года. Статус: Implemented; ожидает визуальной приёмки владельца.
Ветка: `codex/ui-consistency`.
База: `main` / `6a17671`. Evidence: `reports/UI_CONSISTENCY_REPORT.md`.

Прямой запрос владельца разрешает реализацию согласованной визуальной
унификации. Браузерные и визуальные тесты не запускать; владелец проверит
результат вручную в браузере после реализации.

## Scope

Общая типографика, плотность, ширина рабочих областей, двухрежимное desktop-меню
с сохранением выбора, читаемые таблицы и правые панели. Десктоп — приоритет;
планшеты/телефоны — базовое перестроение без отдельного мобильного продукта.
Обзор, входящие, закупка и её существующие карточки/осмотр, поиски, организация,
аудит. Общие примитивы сохраняют согласованность остальных существующих форм.
Бизнес-правила, backend, права, БД, Collector и новые зависимости не изменяются.
Размеры/плотность старых HTML-прототипов заменяются этим стандартом; состав
полей, действий и бизнес-сценарии сохраняются.

Предыдущие screen specs/prototypes не перечитываются: данный Gate меняет только
общий визуальный стандарт по скриншотам и прямому запросу владельца.

метрик, workflow или доступов.

## Стандарт и файлы

- `wwwroot/css/tokens.css`: размеры текста 12 (короткие метки), 14 (вторичный),
  15 (таблицы/контролы), 16 (основной), 18 (раздел), 28 (страница/метрика),
  rem-значения; веса 400/500/600; компактность не уменьшает шрифт.
- `wwwroot/css/components.css` и существующие page/sizing/polish styles:
  общий стандарт вместо произвольных размеров; полная ширина рабочих списков,
  ограниченная длина длинного текста, перенос фильтров и локальный scroll таблиц.
- `Components/Layout/AppShell.razor[.css]`, `wwwroot/js/ui.js`: меню 248/64 px,
  подписи/подсказки и сохранение настройки; на узком экране меню поверх страницы.
- Изолированные стили Home, Collectors, Audit, IncomingCatalogV2,
  ProcurementQueueV2, SiteInspectionPage; минимальная визуальная разметка при нужде.
- UI-kit tokens/instructions, ACTIVE_TASK, этот Gate и итоговый отчёт.
- `scripts/Test-UiPreferences.cjs`: небраузерные проверки сохранения настроек.

## Проверки и приёмка

1. Locked restore / Release build; отсутствие новых warnings/errors.
2. Существующие небраузерные foundation unit tests.
3. Небраузерные проверки хранения настроек меню (в том числе недоступное storage).
4. Проверка CSS, diff и отсутствия изменений backend/пакетов.
5. Browser/visual tests НЕ выполняются по запросу владельца. Ручная приёмка:
   1280/1440/1920/2560 px, планшет/телефон, zoom 125–150%, длинные значения,
   открытые панели, оба режима меню и плотности.

`CaseWorkspace.razor.css`. Проверки: Release build Server, существующие четыре
foundation unit tests, статическая проверка CSS и сохранности обработчиков.

Изменения сделаны в общей рабочей папке, уже переключённой другой задачей на
`codex/parser-workspace-ux`; ветка и указатель активной работы Parser не менялись.
