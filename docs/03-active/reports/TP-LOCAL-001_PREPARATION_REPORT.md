## 2. Решения для review

Один новый TP вместо переопределения старых Gate. Исходный Gate 02 не объявлен
принятым владельцем, SPIKE не закрыт. По умолчанию freshness 24 h, max pages 10,
tabs 1 + 1; архитектура предусматривает 3 + 3 без нового рефакторинга.
ResumeWindow 1 h и остальные интервалы/диапазоны — технические defaults
из таблицы настроек, предложенные для утверждения вместе с TP.

Сбор страниц кликами; checkpoint URL допускается только ранее полученный
из DOM и проверенный. Completed End отличается от LimitReached. Atomic claims,
process ownership и stale token guards защищают очередь. Single-instance
guard предотвращает восстановление задач живого исполнителя.

Изменение SQLite сохраняет legacy данные/историю через versioned upgrade с
backup и rollback. Серверная интеграция пока ограничена моделями и интерфейсами;
server transport/outbox pump/распределённые leases не реализуются.
