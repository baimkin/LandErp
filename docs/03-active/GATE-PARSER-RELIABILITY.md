## Разрешённые изменения

1. Обновлять активные задания пакетно в фоне; историю показывать по 50 записей,
   перечитывать при изменении/навигации, сохранять выбор и действующие элементы UI.
2. Освобождать аренду вкладок и сессии через finally; ограничить ожидание
   закрытия, наблюдать завершение отменённых операций создания браузера/вкладок.
3. Наблюдать автоматические запуски, фиксировать безопасную причину ошибки
   задания и показывать её в окне; сохранять полезные частичные результаты.
4. Ограничить общий объём диагностики в памяти и очищать ключи завершённых работ.
5. Показывать последние известные поля отдельно в Local/Server, сохраняя сырую
   историю и правила Presence/Raw/Parsed, включая явный конфликт площади.
6. Сравнивать все условия Cian; разрешать только известные параметры отображения
   и подтверждённое преобразование SEO-пути в cat.php.
