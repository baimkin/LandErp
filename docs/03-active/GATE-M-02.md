# M-02 — средняя и медиана участников групп; просмотр участников

Разрешён владельцем 2026-09-26 поверх локальной M-01 в той же рабочей копии
и ветке `codex/m-01-median-participation`; база `18a6a1f`. M-01 сохраняется.

## Scope

Существующий рынок Overview и просмотр всех групп используют одну серверную
формулу: средняя арифметическая цен за сотку и медиана одного состава.
Цена за сотку = цена * 100 / площадь в м², decimal/округление проекта.
Пустой состав — null/прочерк и 0 участников, один — обе цены равны его цене.

Состав: IncludeInCalculation и общая пригодность M-01; Sold/Dismissed допускаются,
Duplicate/Fake/RemovedAtSource запрещены. Невалидные данные не снимают отметку.
Принадлежность группе — только существующие search/job/observation факты;
повторы внутри группы не размножают участника, одна отметка действует во всех
его группах. Без группы в групповой расчёт не включать.

Старые период/типы земли/границы цены перестают влиять на формулу. Удаляются
их misleading controls/подписи, но не schema/history данные. Расчёт при чтении,
без snapshots/cache/jobs. Временные фильтры списка не меняют состав метрик.

Просмотр участников — явный режим существующей Incoming, предполагаемый URL
`/incoming?participants=<groupId>`. Общий отбор используется метриками и списком.
Нет скрытого OR пресетов/Incoming-состояния/периода. Число всех участников
отличается от результата явного текстового поиска. Существующие детали и
отдельное/массовое исключение M-01 переиспользуются; исключение глобальное.
Переход доступен только с Incoming.Read; существующие права Overview сохраняются.

## Вопрос представителя подтверждённого объекта

Найден реальный допускаемый кодом случай: LinkCatalogItemsAsSameObjectAsync
переводит исходное объявление в Duplicate только из Incoming. Два пригодных
отмеченных Sold/Dismissed можно связать в один ObjectGroupId без снятия отметок.
Они дают разные цены одного подтверждённого участка.

Владелец согласовал: в каждой группе поиска объект считается один раз по
кандидату с самым свежим наблюдением именно в этой группе. Рассматриваются
только отмеченные пригодные кандидаты; равные даты — стабильный ID; отсутствие
даты — после датированных, с детерминированным выбором. В текущей схеме участие
в группе требует observation с обязательным ObservedAt, поэтому undated-кандидаты
не создаются искусственно. Цена Sold — цена источника, не цена сделки.

Этот представитель используется формулой, количеством и списком. Исключение
одного источника не снимает отметки других: следующий подходящий может стать
представителем. Поведение явно поясняется в режиме участников.
