# Статус правил разработки

`legacy_clinerules_reference.txt` сохранён как полный исторический адаптированный
вариант правил. Он не предназначен для автоматического чтения при каждой задаче.

Исполняемые правила разложены по назначению:

- `AGENTS.md` — глобальные правила Codex и других агентов;
- `.roo/rules/` — общие правила Zoo Code;
- `.roo/rules-architect/` — режим планирования;
- `.roo/rules-code/` — режим реализации;
- `.roo/rules-debug/` — режим диагностики;
- `docs/03-active/ACTIVE_TASK.md` — текущий scope;
- активный Gate — единственное разрешённое изменение.

При расхождении используется приоритет из `AGENTS.md`.
