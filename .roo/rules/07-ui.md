# LandErp — Blazor и визуальная система

- UI строится на Blazor Web App и компонентах Land ERP.
- Использовать локальный Bootstrap CSS как grid/forms/utilities; без CDN и
  Bootstrap JavaScript по умолчанию.
- Не добавлять MudBlazor, Radzen, Syncfusion, Telerik и другой component suite.
- Использовать токены FP-003; не вводить локальные цвета, размеры и статусы без причины.
- Системный стек шрифтов; внешние web-font не загружать.
- Стандартный control — 40 px; строка таблицы — 44 px, compact — 36 px.
- Каждый асинхронный экран имеет loading, refreshing, empty, error, forbidden,
  conflict и success состояния по применимости.
- Цвет не является единственным носителем статуса.
- Формы имеют постоянные label, серверную валидацию и защиту от повторного submit.
- Компоненты с подписками/JS реализуют корректное освобождение ресурсов.
