# FP-052 — Портфель и карточка проекта инвестора

**Версия:** 0.1  
**Статус:** Черновик  
**Модули:** InvestorPortal  
**Зависимости:** FP-042–FP-046, FP-051, FP-003

## 1. Результат

Инвестор видит назначенные проекты, их понятную стадию, опубликованные ключевые
цифры, события, фото и документы — без внутренних черновиков и служебных рисков.

## 2. Портфель

Карточка списка: проект, стадия, период, статус участия, опубликованный капитал,
последнее обновление и следующий ожидаемый этап. Суммарные цифры показываются
только при одинаковой валюте/методике либо раздельно.

## 3. Карточка проекта

Обзор, ход работ/таймлайн, лоты, опубликованный plan–fact, участие инвестора,
документы и обращения. Каждая секция имеет `PublishedAt` и пояснение прогноз/
согласовано/факт. Отсутствие публикации не заменяется нулём.

## 4. Read model

InvestorPortal использует отдельный опубликованный snapshot, сформированный из
ProjectsFinance. Внутреннее изменение не становится видимым автоматически.
Отзыв snapshot/секции сохраняет аудит и понятное состояние для инвестора.

## 5. UX

Простой адаптивный интерфейс, ясные статусы, без перегруженной ERP-навигации.
Фото оптимизированы; документ открывается после повторной проверки scope.
Показывается дата свежести и контакт для вопроса.

## 6. Тесты и DoD

- только назначенные проекты;
- опубликованный snapshot стабилен при изменении draft;
- прогноз и факт визуально/текстово различны;
- отозванная секция недоступна по старой ссылке;
- пустые состояния не показывают нулевую прибыль;
- мобильный и desktop UX доступны;
- проект Химки может быть представлен понятной историей 30 → 28 соток.

## 7. Открытые вопросы

- разрешённая детализация финансов;
- набор стадий для внешнего пользователя;
- частота публикаций;
- нужен ли общий показатель портфеля.
