## Цель

Пользователь понимает, что можно сделать с объектом сейчас, кто должен принять следующее решение и почему действие недоступно. Убрать неопределённое «Решение ожидает текущего исполнителя либо этап уже завершён». Улучшить интерфейс существующего процесса, не перестраивать workflow.

## Scope

1. Адресно изучить существующие серверные правила CanManagerDecide/CanHeadDecide, стадии, назначения, подтверждение покупки и связанные формы. Сделать короткое соответствие «реальная стадия/права → текст состояния → допустимые действия». Не сочинять новую матрицу полномочий.
2. В карточке, панели очереди и окне решений показать конкретное состояние: ожидается решение указанного сотрудника/роли, работа одобрена, объект отклонён, наблюдение, покупка оформлена — только согласно фактическим данным. Не показывать имя сотрудника без данных/права доступа; если назначение отсутствует, объяснить это честно.
3. Понятные названия существующих действий: передача руководителю, возврат менеджеру, продолжение работы, наблюдение, отклонение. Проверить согласованность названия кнопки, заголовка формы и результата. Не вводить новые переходы.
4. Не открывать пустую форму с общей отговоркой. Если нет доступных действий, показать конкретное состояние и причину в месте принятия решения. Где причина — блокирующие проверки, новые данные источника или другое действующее условие — дать существующий переход к нужному разделу, если это можно сделать без расширения продукта.
5. Оформление покупки — отдельное понятное действие существующего механизма. Одобрение/продолжение работы не означает покупку. Сохранить необходимые подтверждения и обязательные причины значимых решений; не добавлять дополнительные подтверждения просто ради формальности.
6. Права остаются на сервере. Изменение состояния/назначения другим сотрудником во время открытой формы не должно приводить к ложному успеху или обходу проверки; показать актуальную причину/предложение обновить, сохранить введённое где уместно.
7. Не связывать ViewedDataRevision из U-02 с бизнес-разрешениями: открытие сравнения не снимает ReviewedDataRevision/SourcesChanged и ограничения согласования.
