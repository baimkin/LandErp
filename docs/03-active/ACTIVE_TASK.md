## Scope и статус

Разрешены только публикация проверенного состава поверх актуального origin/main,
сохранение истории и пользовательских данных, переход основной папки на main.
Подготовка — codex/nov23-main-sync от c3be8f9; рабочий checkout после синхронизации — main.
Включены Incoming fast actions + пакет A, независимые повторы поисков, черновики
осмотра и отдельный Parser с их тестами/спецификациями/отчётами.

Код проверен на main-based копии: полная Release build 0 warnings/errors,
38/38 серверных проверок (5 browser), все 285 выбранных Parser offline,
8/8 inspection JS и 36/36 map JS. В публикации нет новых функциональных правок.
Факт push и итоговый SHA подтверждаются совпадением GitHub main, origin/main и
локального main; evidence — artifacts/nov23-main-sync/verification.json и итоговый
ответ владельцу. После успешной синхронизации этот Gate завершён.

Новая реализация не активирована. Пакет B не начинать. Production, развёртывание,
рабочая БД/preview, обновление установленного Parser и live источники не разрешены.
Commit/push разрешены текущим запросом; прежние запреты в архиве исторические.
