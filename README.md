# LandErp

LandErp — будущая ERP-система для поиска, предварительной оценки и ведения
инвестиционных проектов с земельными участками.

Сейчас репозиторий находится на исследовательском этапе. Production-кода ещё
нет. Первая активная работа — `SPIKE-001`: проверка жизнеспособности парсинга
Avito через C# 14, .NET 10 и Microsoft.Playwright.

## Сборка и запуск Gate 01

Offline-каркас `LandErp.ParserSpike` использует C# 14 и .NET 10. SDK 10.0.100
закреплён в `global.json`; допускаются стабильные patch-обновления той же feature band.
Gate 01 использовал только BCL; в Gate 02 добавлены Microsoft.Playwright 1.62.0,
Microsoft.Data.Sqlite 10.0.0 и SQLitePCLRaw.bundle_e_sqlite3 2.1.13.
Тесты используют MSTest; версии заданы
централизованно, транзитивные версии закреплены в `packages.lock.json`.

```powershell
dotnet --info
dotnet restore LandErp.slnx --locked-mode
dotnet build LandErp.slnx -c Release --no-restore
dotnet test LandErp.slnx -c Release --no-build --filter 'TestCategory!=Live'
dotnet run --project src/LandErp.ParserSpike -c Release --no-build -- --help
dotnet run --project src/LandErp.ParserSpike -c Release --no-build -- unknown
$LASTEXITCODE # ожидается 2
```

CLI предоставляет только help и отклоняет остальные команды без вывода входных
аргументов. Gate 01 не обращается к Avito и не запускает браузер.
Контракты отделяют классификацию, outcome и `Raw / Parsed / Presence`.
Для текстового поля допустим raw без parsed; typed value представлен nullable
value type. Диагностика содержит только opaque GUID, без файловых путей.
URL-метаданные допускают публичные HTTP(S) URL без credentials, query и fragment;
чувствительные данные в любых строковых значениях передавать запрещено.

## Запуск Windows-приложения TP-LOCAL-001

Версия для локального испытания Avito и Cian:
`artifacts/local-001-map-diagnostic/bin/LandErp.ParserSpike.Desktop/release/LandErp.ParserSpike.Desktop.exe`.

Нужны Windows x64, .NET 10 Windows Desktop runtime и установленный Chrome или Edge.
Для повторной сборки:

```powershell
dotnet restore LandErp.slnx --locked-mode --artifacts-path artifacts/local-001-map-diagnostic
dotnet build LandErp.slnx -c Release --no-restore --artifacts-path artifacts/local-001-map-diagnostic
```

1. Откройте приложение, вставьте ссылку поисковой выдачи и нажмите «Добавить / сохранить».
   Источник определяется по адресу; ручной выбор проверяется на соответствие ссылке.
   SEO-ссылки, поиск с карты и дополнительные фильтры сохраняются. Ссылку отдельного
   объявления тоже можно сохранить, но detail-парсер ещё не поддерживается — это
   явно сообщается. Ошибка сохранения показана рядом с полем URL; ввод не теряется.
2. Добавьте остальные ссылки, отметьте нужные. Список сохраняется между запусками.
3. Во вкладке «Настройки» задайте страницы (по умолчанию 10), свежесть (24 часа),
   срок продолжения (1 час), вкладки (1 Avito + 1 Cian, доступны 3+3), браузер,
   прокрутку и интервалы. Нажмите «Сохранить настройки». Для быстрой плавной
   прокрутки: шаг 100 px, интервал колеса 20 мс, 12 событий в серии, пауза 40 мс.
   Ранее сохранённые значения шага и интервала остаются вашими.
4. При необходимости выберите поиск и нажмите «Открыть поиск вручную», войдите.
   Парсинг при этом не запускается. Используются отдельные постоянные профили.
5. Нажмите «Обработать отмеченные». Очередь распределяет ссылки между вкладками;
   каждая вкладка читает страницы одной ссылки последовательно. Переход — кликом
   по следующему номеру или кнопке, без самостоятельного конструирования адреса.
6. При CAPTCHA/входе/429 источник приостанавливается с оповещением. Пройдите проверку
   вручную в указанной вкладке и нажмите «Продолжить Avito» или «Продолжить Cian».
   Проверяется именно заблокированная вкладка; автоматических повторов нет.
7. «Пауза» / «Продолжить» управляют всей очередью. «Остановить» сохраняет частичные
   результаты. После повторного старта полностью завершённые свежие страницы
   пропускаются; в пределах срока продолжения сбор идёт со следующей страницы.
   Незавершённая страница читается заново. «Начать заново» отключает пропуск.
8. В «Сохранённых объявлениях» доступны фильтры источника/поиска/задачи, поиск,
   сортировка цены, страницы по 100 записей, текущее известное состояние и исходная
   история. Выберите задачу в очереди для её журнала и JSON-экспорта.

Для карты Avito сохраняйте ссылку с выделением и нажимайте «Обработать отмеченные».
Приложение прокручивает правый список, собирает JSON-карточки и сохраняет контур/координаты.
Запись диагностического JSON включать для сбора не требуется.
При запуске карты журнал collection.jsonl автоматически получает события «Диагностика карты»:
порции/повторы/исключения, ID из DOM без JSON и состояние прокрутки. Координаты видны в таблице
и подробностях; контур — в JSON-экспорте задачи. Код precision хранится без предположения о метрах.
На карте предел страниц означает число порций items (обычно по 10 карточек).
Счётчик журнала показывает уникальные объявления / totalCount. Неполнота, изменение
счётчика или отсутствие контура не подтверждают свежесть; частичная карта стартует заново.
При сбросе/смене зоны появится оповещение: восстановите исходную область и нажмите
«Продолжить Avito». Если исходную область восстановить нельзя — остановите задачу,
создайте новый поиск с новой зоной; автоматического восстановления пока нет.
Повтор обновляет last seen и связь с поиском; изменённые поля попадают в историю
независимо от возраста предыдущего наблюдения. Свежесть управляет пропуском обхода:
если сайт не был прочитан, изменения обнаружить невозможно.

Диагностический журнал доступен во вкладке «Диагностика» → «Обновить журнал».
Файл: `local-data/diagnostics/collection.jsonl`; содержит действие, время, страницу,
задачу, вкладку, тип ошибки и безопасное сравнение адресов. HTML, cookies,
заголовки запросов и исходные тексты браузерных исключений не записываются.

Для исследования карты: «Диагностика» → «Начать запись JSON», затем выберите
сохранённую ссылку и «Открыть поиск вручную». Выделите область и прокрутите
правый список в браузере. Сбор объявлений запускать не требуется.
Затем «Остановить запись JSON» → «Показать JSON»; путь файла указан в просмотре.
Файлы: `local-data/diagnostics/browser-json/`. Запись выключена по умолчанию,
сохраняются обезличенные структуры ответов и отдельные публичные значения,
а не полный сетевой дамп. Для рабочей/сброшенной зоны запишите отдельные сеансы.
Для Avito записываются ответы карточек и меток карты; раздел `Map` сохраняет
подтверждённые ID, числовые координаты и безопасно декодированную геометрию.
Отчёт: [уточнение диагностики](docs/03-active/reports/TP-LOCAL-001_JSON_COORDINATES_REPORT.md).

База: `local-data/spike-002.sqlite`, обновляется с резервной копией и сохранением
истории Gate 02. Схема SQLite теперь 2; старое приложение её не открывает.
Перед обновлением закройте старую версию; резервная копия создаётся автоматически. Профиль Avito сохраняется в `browser-profiles/spike-002/{chrome|msedge}`;
Cian — `browser-profiles/local-cian/{chrome|msedge}`. Профили, база и резервные копии
исключены из Git. Второй экземпляр с той же базой не начинает сбор.
Перед вашим испытанием закройте старый прототип Gate 02, если он занимает тот же
профиль: приложение не закрывает чужие окна автоматически.

Собирается DOM основной выдачи: ID, URL, заголовок, цена, площадь и её противоречия,
назначение, адрес, транспорт, полное доступное описание, текст даты, продавец,
профиль/тип/статистика при наличии, badges, доступные URL фотографий, явная цена
за сотку и отдельно вычисленная. Телефоны не раскрываются, сообщения не отправляются.
Реклама/рекомендации/другие регионы отделяются; неизвестная разметка даёт ошибку.

Офлайн-проверки, включая присланную страницу Cian и 10 000 синтетических записей,
не являются доказательством стабильного live-сбора. Испытание реальных ссылок обоих
источников выполняет владелец следующим шагом. Начните с 1 вкладки и 2–3 страниц.
Отчёт: [TP-LOCAL-001](docs/03-active/reports/TP-LOCAL-001_REPORT.md).
Существующие Gate 01 CLI/контракты и проверки прежнего окна сохранены для регрессии.
