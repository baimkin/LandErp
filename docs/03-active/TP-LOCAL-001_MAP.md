# TP-LOCAL-001 — дополнение: карта Avito

Утверждено прямым запросом владельца 2026-09-14. Ветка spike/001-avito-viability.
Это продолжение локального TP, не новый Gate и не разрешение production.

## Реализация

- При карте Avito прокручивать колесом правый список, с существующими настройками скорости.
- Наблюдать только публичные `/web/1/map/markers` и `/js/1/map/items`; извлекать бизнес-поля JSON, не сохранять сырые ответы/секреты.
- Реальный ID/URL, название, цена, площадь из текста, описание, адрес, дата и фотографии при наличии. Продавец из доступного DOM; телефон не раскрывать.
- Сохранять проверенную пару широта/долгота и исходный код precision без выдуманной точности в метрах.
- Для drawId требовать подтверждённый GeoJSON Polygon, сохранять его отдельно от прямоугольника обзора. Исключать внешние точки. Сброс/изменение зоны требует ручной проверки.
- Карта является одной логической страницей. MaxPages ограничивает число принятых порций items за один запуск; незавершённая карта перечитывается с начала, без выдуманного сетевого cursor.
- Завершение: низ правого списка, стабильность, отсутствие загрузки/ошибок, число уникальных ID совпадает с totalCount. Без счётчика или при несовпадении — частичные данные и явная причина, без свежести.
- Source+ExternalId определяет объект. Изменения сохранять независимо от свежести; одинаковое содержимое не увеличивает историю. Повторные встречи сохранять для фильтров поиска/задачи. Отсутствие поля не стирает известное значение.
- CAPTCHA/авторизация/ограничение приостанавливают источник. Никакого обхода защиты.

## Проверки

Офлайн JSON: ID/URL, координаты, поля, контур/дырки, внешние точки и изменение зоны.
SQLite: повтор/изменение/возврат цены, связи с задачами, сохранение контура и миграция с резервной копией.
Браузер: колесо прокручивает правый блок, карта не масштабируется; JSON приходит независимо от диагностики.
Очередь: неполнота не даёт Completed/SkippedFresh, предел, ручная пауза и отмена.
Сборка Release и все существующие офлайн-проверки. Live проверяет владелец после отчёта.
