# Исходные материалы для парсинга

Репозиторий намеренно не содержит сырые HTML-страницы, browser profile,
скриншоты с персональными данными, cookies и trace-файлы.

## Локальное размещение

После клонирования пользователь может положить исходные материалы в:

`docs/15-source-materials/private/`

Содержимое каталога исключено из Git. В Gate 02 из исходных файлов создаётся
отдельный очищенный набор в `fixtures/sanitized/` после проверки.

## Перед переносом fixture в Git

- удалить cookies, tokens, auth headers и session data;
- удалить личные сообщения и контактные данные, не нужные тесту;
- проверить изображения и встроенные data URL;
- ограничить размер;
- добавить metadata: источник, дата, page kind и назначение;
- зафиксировать ожидаемый результат;
- получить review sanitization.

Сохранённый HTML не считается достоверным описанием live DOM и проверяется
отдельно.
