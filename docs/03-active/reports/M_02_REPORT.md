## Реализовано

- Обзор «Рынок по группам поиска» и существующий просмотр всех групп используют
  одну серверную формулу и один состав через `CatalogMarketParticipants`.
- Фактический кандидат: IncludeInCalculation и общая пригодность M-01. Единое
  выражение причины пригодности используется в SQL и для пояснения человеку;
  второго независимого правила цены/площади/валюты/состояний нет.
- Цена за сотку = Price * 100 / AreaSquareMeters. Средняя — арифметическая
  этих отношений, не отношение суммарной цены к суммарной площади.
  Медиана — центральное значение либо среднее двух центральных. Промежуточные
  цены не округляются для агрегации; итоговые decimal округляются сервером
  до 4 знаков ToEven, как цена за сотку в существующей таблице. Home сохраняет
  прежний компактный денежный формат. Оба представления получают одни значения.
- Пустой состав даёт null/прочерк и «0 участников». Для одного участника обе
  метрики равны его цене за сотку.
- Sold и Dismissed входят при отметке и пригодности. Duplicate/Fake/
  RemovedAtSource исключены. Утрата пригодности временно исключает из состава,
  не снимая отметку; исправление данных возвращает в состав. Ручное false
  сохраняется. Непригодные остаются видны с причиной в обычном Incoming M-01.
- Группа определяется по существующим observation → job → search → active group
  с проверками организации. Повторные наблюдения и поиски одной группы
  сворачиваются в одного кандидата. Отметка действует во всех группах объявления;
  объявления без групповых фактов не добавляются по адресу/названию.
- Старые настройки периода, типов земли и границ цены больше не влияют на
  показатели. Их controls и объяснения старой формулы удалены из Home.
  Старые данные/контракты настройки/history сохранены; applied migrations
  не менялись. Обычные фильтры Incoming продолжают служить отбору для отметок.
- Пересчёт при каждом чтении, без снимков, новых jobs, кэша или live push.
  SQL сначала фильтрует отмеченных пригодных и сворачивает наблюдения; сервер
  материализует только скалярные кандидаты запрошенных групп, затем выбирает
  представителей и агрегирует decimal. Полные Listing/фото/описания для метрик
  не загружаются. Нагрузочная проверка по запросу не выполнялась.

## Представитель подтверждённого объекта — решение владельца

Подтверждён кодовый случай: LinkCatalogItemsAsSameObjectAsync переводит в
Duplicate только исходный Incoming; связанные Sold/Dismissed могут оставаться
отмеченными пригодными источниками одного ObjectGroupId с разными ценами.
Вопрос был передан владельцу до зависимой реализации и согласован.

В каждой группе поиска один подтверждённый объект голосует один раз. Среди
его отмеченных пригодных источников выбирается самый свежий ObservedAt
**в этой группе**, при равенстве — ID по возрастанию. Неотмеченный или
непригодный свежий источник не вытесняет участника. Без даты — после
датированных, затем ID; текущая схема даёт групповую принадлежность через
observation с обязательным ObservedAt, искусственные undated связи не создаются.
У объявления без ObjectGroupId собственная отдельная идентичность.

Формула, число и список используют один выбор. Исключение представителя снимает
только его глобальную отметку: другой отмеченный пригодный источник может
занять его место. Другие отметки не снимаются молча. Это явно поясняется в
режиме участников. Цена Sold названа ценой источника, не фактической ценой сделки.

## UI и права

- «В расчёте: N» в обоих представлениях открывает
  `/incoming?participants=<SearchGroupId>`. Ссылка выводится только с
  Incoming.Read, даже если пользователь имеет право на показатели Overview.
- Используется та же таблица, детали, сортировка и команды M-01. Серверный режим
  Participants требует доступной группы и нормализует запрос: нет скрытых OR
  пресетов, состояния Incoming, возраста, цены, типа или рабочего среза.
- Видны выбранная группа, цена, площадь, цена за сотку и источник.
  Сохранённые фильтры, рабочие плитки и расширенные условия в этом режиме скрыты.
  Есть явные переходы в обзор и обычные входящие.
- «В расчёте: N» — весь состав группы; «Найдено по поиску: M» — его текстовый
  подрезультат. Поиск не изменяет метрики и не заменяет выбранного представителя.
- Обычное и массовое исключение, включая все найденные страницы, используют
  общий отбор M-01. После записи перечитываются список/числа; метрики меняются
  при следующем чтении. Предупреждение поясняет глобальность исключения и замену
  источника того же объекта. Права обработки проверяются существующими командами.
- Права Overview не ослаблены: Incoming.Read без доступа к Overview не открывает
  рыночный сервис; доступ к Overview без Incoming.Read не открывает объявления.
