# FP-023 — Наблюдение за ценой и повторным контактом

**Версия:** 0.1  
**Статус:** Черновик  
**Модули:** ManagerWorkspace, PropertyCatalog  
**Зависимости:** FP-013, FP-020, FP-022

## 1. Результат

Интересный объект не теряется после отказа продавца снизить цену. Менеджер задаёт
условие цены, дату или событие, а система возвращает объект в работу с объяснением
и историей — в том числе через полгода.

## 2. Правила наблюдения

`WatchRule` поддерживает: цена не выше суммы, снижение не менее процента/суммы,
конкретную дату, повторное появление объявления и ручное событие. Несколько
условий связываются явно `любое/все`; сложные формулы не входят в MVP.

## 3. Поток

Менеджер создаёт правило из решения `Наблюдать`, видит базовую цену/дату и
ответственного. Новое Observation или планировщик проверяет условие. При
срабатывании создаётся один `DecisionQueueItem`, правило помечается сработавшим
либо остаётся активным по выбранной политике.

## 4. Данные

Хранятся правило, базовое наблюдение, порог, следующий review, состояние,
срабатывания и отмена. Деньги не представлены `double`; валюта явна. Изменение
правила создаёт новую версию, прошлые срабатывания не пересчитываются.

## 5. UI

В карточке видны активные наблюдения и ближайшая дата. Очередь показывает
«вернулось потому что цена снизилась с X до Y» или «наступила дата контакта».
Пауза источника не удаляет календарный follow-up.

## 6. Устойчивость и тесты

- одно событие не создаёт несколько возвратов;
- позднее Observation оценивается по времени наблюдения;
- изменение валюты/неизвестная цена не считается снижением;
- отменённое правило не срабатывает;
- дата корректна в часовом поясе пользователя;
- права и аудит создания/изменения/отмены;
- E2E: отказ → шесть месяцев/порог → возврат в очередь.

## 7. Definition of Done

- условия понятны без формул;
- возврат содержит причину и исходную цену;
- нет дублей при повторной доставке;
- просроченные follow-up видны руководителю;
- история переговорного ожидания не теряется.

## 8. Открытые вопросы

- значимое изменение цены по умолчанию;
- повторяется ли правило после срабатывания;
- кто наследует наблюдения уволенного/отсутствующего менеджера;
- нужен ли внешний календарь позднее.
